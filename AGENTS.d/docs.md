# 文档体系 / 编写规范

## 1. 目录体系

| 路径 | 内容 | 维护者 |
|------|------|--------|
| `README.md` | 项目入口说明 | 协调者 |
| `docs/design.md` | **唯一权威设计文档**，变更须重新获批 | 协调者 |
| `docs/standards/` | 语言编码规范 | 文档 Agent |
| `docs/research/` | 调研报告（一手来源 + 链接） | 调研 Agent |
| `docs/memory/` | 项目记忆仓库（见 memory.md） | 全员 |
| `AGENTS.d/` | 多 Agent 协作约定 | 协调者 |

## 2. 编写规范

- 中文为主；代码/命令/标识符保留原文；
- 每条关键结论附来源（调研报告必须附 URL）；
- 文档与代码必须同步：改代码即改文档，改文档即获批；
- 状态类文件（`status.md`）保持「当前事实」，历史交给 git。

## 3. 文档变更控制

- 设计文档（design.md）的任何变更：先更新、再提请用户批准、获准后生效；
- 其他文档变更：随对应阶段提交。
