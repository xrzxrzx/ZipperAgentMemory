# 测试规范

## 1. 层次

| 层 | 覆盖 | 位置 | 运行 |
|----|------|------|------|
| 单元测试 | 路径沙箱、原子写、索引、MCP 参数校验 | `*_test.go` 与被测代码同包 | `go test ./...` |
| 集成测试 | MCP 握手、迁移脚本、watcher 端到端 | `integration/` | 手动/脚本 |
| 验收测试 | 每阶段验收标准 | 阶段验收记录 | 阶段结束 |

## 2. 要求

- 关键逻辑必须有单元测试，表驱动优先；
- 测试不依赖网络；临时文件用 `t.TempDir()`；
- 资源实测（内存/CPU）是阶段 2 起的验收证据，`/usr/bin/time -v` 记录在案；
- 提交前 `go test ./...` 全绿。

## 3. 测试 Agent 独立验证

阶段验收时若需独立验证，由测试 Agent 按任务书验收标准执行，产出测试报告（结果 + 证据 + 结论）。
