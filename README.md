# ZipperAgentMemory

AI 跨平台永久性记忆工具：在 Linux 低资源服务器上运行的常驻进程，维护一个 **Markdown + CSV 文件型记忆库**，经 **MCP（stdio）** 供 Claude / Cursor / DSH 等 Agent 读写与检索；记忆库即普通目录树，支持 **目录复制** 与 **git** 双模式迁移。
