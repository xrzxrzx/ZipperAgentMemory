## 需求-006 已对齐要点（2026-10-18 讨论，待该需求启动时冻结为 S1）

- **软删除**：文件移入回收站目录（非物理删除），阅读页需能**单独查看回收站区域**。
- 软删除**不需要二次输入口令**（因此 CSRF 缓解方案须在 S1 定：`SameSite` / Origin 校验 / 自定义请求头，不得靠"用户点确认"当安全边界）。
- **只有在回收站执行「清除」才是物理删除** —— 该动作的保护级别待 S1 明确。
- **UI 美化**：Agent 先出 **2 版视觉方案**（截图或静态页）供用户挑选，选定后按该方案验收；"好看"不可判定，以选定方案为准。
- 拆分决定：**先 005 后 006**，两轮独立文档与验收。
- 已知设计冲突：当前 `design.md` 决策 8 为「只读无写接口」，`pkg/web/web.go:31` 注释同 —— 加删除须**修改并重新获批 `design.md`**（`AGENTS.d/docs.md` §3）。
