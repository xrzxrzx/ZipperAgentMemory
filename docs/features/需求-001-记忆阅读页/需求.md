# 需求-001-记忆阅读页

> 状态：已确认　版本：v1　更新：2026-10-05

## 1. 背景与要解决的问题

记忆库目前只能通过命令行或专门的客户端工具访问。用户在外出、或手边只有一台带浏览器的设备时，**看不到自己的资料**。

同时，记忆库里存着笔记、项目资料与个人密码资料，任何"打开网页就能读"的做法都必须先解决一个问题：**谁可以读**。用户要求：进入阅读页需要输入一个**长期有效、不会过期**的口令。

## 2. 用户与场景

| 项 | 内容 |
|---|---|
| 使用者 | 用户本人（记忆库唯一所有者） |
| 使用情境 | ① 出门在外用别人的电脑/手机，临时查一条笔记；② 在家想舒服地翻资料、按关键词检索 |
| 前提 | 记忆库内容与敏感程度不变（库内已含密码类资料） |

## 3. 需求条目

| 编号 | 要什么 | 为什么 | 验收标准 | 优先级 |
|---|---|---|---|---|
| REQ-01 | 用浏览器打开一个固定网址即可进入阅读页 | 浏览器是最通用的入口 | 打开网址即进入阅读页；未登录时要求先输入口令 | P0 |
| REQ-02 | 输入一次口令后即长期保持登录，口令永不过期 | 不想反复输入，也不想某天突然失效 | 正确口令可进入；口令无有效期；关闭浏览器再打开仍是登录态；换设备需重新输一次 | P0 |
| REQ-03 | 按目录逐级浏览，正文以排版后的形式显示 | 资料是按目录存放的笔记与文档 | 能从根目录逐级点进子目录并看到正文；中文显示正常（不乱码） | P0 |
| REQ-04 | 全文检索，且支持多个关键词 | 想同时限定几个词来缩小范围 | 输入多个词（空格分隔）能搜到**同时包含这些词**的文件；可切换为「任一关键词命中」模式；结果给出文件路径与命中片段 | P0 |
| REQ-05 | 可下载原始文件、可复制文件路径 | 备份、引用、贴到别处 | 下载所得文件与库中原文件**完全一致** | P1 |
| REQ-06 | 未授权访问一律被拒绝，且不泄露任何库内容 | 库内含密码类资料，泄露代价极高 | 无口令或错误口令时，**看不到任何文件内容、目录名或搜索结果**；被拒绝时给出明确提示而非空白页 | P0 |
| REQ-07 | 阅读页覆盖整个记忆库（含密码类资料目录） | 本人需要随时查阅全部资料 | 登录后可读到库内任意文件；**风险由用户明确确认接受**（记录在技术方案与设计文档） | P0 |
| REQ-08 | 除阅读入口外的同一网址下其他地址不对外开放 | 缩小暴露面 | 除阅读入口外，该网站其他地址均不可访问 | P1 |

## 4. 不做什么

- ❌ **不做在线编辑 / 写入**：阅读页只读，任何修改仍走原有客户端工具
- ❌ **不做多用户与口令管理**：只有一个人用，不建账号体系、不做多人权限
- ❌ **不做口令有效期、自动过期、找回**：明确要求长期有效
- ❌ **不新建独立域名、不申请新证书**：改用同一网址下的路径式入口
- ❌ **不做手机端专门适配**：能在手机上正常阅读即可
- ❌ **不改动现有客户端工具的接入方式与访问策略**

## 6. 术语表

| 术语 | 含义 |
|---|---|
| 记忆库 | 用户的全部笔记与资料，以普通文件形式分目录存放 |
| 阅读页 | 在浏览器里浏览与检索记忆库的页面 |
| 口令 | 进入阅读页需要输入的、长期有效的凭据 |
| 敏感资料 | 库内密码类资料所在的部分 |
