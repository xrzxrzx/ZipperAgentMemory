1. 以**管理员**身份打开记事本（开始菜单搜 notepad → 右键"以管理员身份运行"）

5. 浏览器打开 `http://memory.zipper.net.cn/`（**注意用 http**；用 https 会先报证书域名不匹配，接受后会跳到 http 正常页）
