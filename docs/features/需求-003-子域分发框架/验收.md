### 新增一个服务的标准步骤

```nginx
# /etc/nginx/conf.d/<子域名>.conf
server {
    listen 80;  listen [::]:80;
    server_name <子域名>.zipper.net.cn;
    location / {
        proxy_pass http://127.0.0.1:<端口>;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

步骤：① 写上述 conf（名字用子域名，便于查找）→ ② `nginx -t` → ③ `systemctl reload nginx` → ④ 若该服务**需要鉴权或含敏感数据**，先给它签证书（`certbot certonly --webroot -w /var/www/acme -d <子域名>.zipper.net.cn`）并只在 `:443` 暴露 → ⑤ 更新本节映射表。
