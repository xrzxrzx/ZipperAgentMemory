## 6. 回滚方式

服务器保留 `zipper-agent-memoryd.bak-20261018-203308`；如需回滚：

```bash
cd /opt/zipper-agent-memory
mv zipper-agent-memoryd.bak-20261018-203308 zipper-agent-memoryd
systemctl restart zipper-agent-memory.service
```

> 注意：回滚后索引格式回到 v1 时代，需 `rebuild-index`（旧二进制不支持 `body_bg` 列，会读自己的 5 列 schema；`.trash` 目录内容建议一并清理）。

## 7. 2026-10-20 追加：目录软删除（需求扩展）

> 背景：S1 原定「只做单文件删除」；用户实际使用中要求「目录也能删，连同文件夹一起进回收站」。

| 层 | 改动 |
|---|---|
| `pkg/memory` | `MoveToTrash` 支持目录（同卷 `os.Rename` 整树搬走，不复制数据）；新增 `WalkFiles` 递归列文件 |
| `pkg/index` | 新增 `RemovePrefix`（`substr` 精确前缀，避免 `LIKE` 通配符转义） |
| `pkg/web` | 删除按 `IsDir` 分派 `Remove` / `RemovePrefix`；恢复对目录先 `WalkFiles` 再逐个 `reindex` |
| 前端 | 目录节点 hover 显示 `×`，`confirm` 明示「目录 xxx/ 及其全部内容」 |

**测试**：`TestMoveToTrashDirectory`、`TestWalkFiles`、`TestTrashDeleteDirectory`；全量 7 包绿。
