## 3. 方案选型

### 3.1 设计令牌（暗色 Fluent）

| 令牌 | 值 | 说明 |
|---|---|---|
| `--bg-base` | `#1f1f1f` | Fluent 暗色底 |
| `--layer` / `--layer-alt` / `--input` | `#272727` / `#2d2d2d` / `#2b2b2b` | 层级表面 |
| `--stroke` / `--stroke-strong` / `--stroke-control` | `rgba(255,255,255,.08/.14/.09)` | Fluent 用低透明度白描边，不用灰硬边 |
| `--text` / `--text-2` / `--text-3` | `rgba(255,255,255,.96/.62/.52)` | .52 是为让 12px 小字仍 ≥4.5:1（实测 5.13） |
| `--accent` / hover / press / fill | `#60cdff` / `#7fd8ff` / `#4cb8e8` / `rgba(96,205,255,.14)` | Win11 暗色强调色 |
| `--on-accent` | `#002b4d` | 强调色上的深色字（Fluent 规范；实测 8.04:1） |
| `--danger` / strong / fill / stroke | `#ff99a4` / `#ff6b7a` / 12% 填充 / 34% 描边 | 危险动作用「subtle」样式：平时低调，悬停才浮现 |
| `--radius-panel` / `--radius-ctl` | `8px` / `4px` | Win11 两档圆角 |
| `--shadow-2` / `--shadow-8` | 2 层 / 8 层阴影 | Fluent 层级 |
| `--motion` | `150ms cubic-bezier(.13,.79,.32,1)` | Fluent 标准曲线 |

### 3.2 材质实现（Mica / 亚克力）

- **Mica 近似**：`body` 用两处低透明度径向渐变（强调蓝 10%、紫 7%）叠在 `#1f1f1f` 上 —— 让亚克力面板"有东西可模糊"；
- **亚克力**：`.panel`/`.topbar`/`.statusbar`/`.login-card` 用半透明底 + `backdrop-filter: blur(30px) saturate(150%)`；
- **降级**：全部包在 `@supports (backdrop-filter: blur(1px))` 内，不支持的浏览器直接用纯色 `#272727`（视觉略平，但完全可用）。

### 3.3 关键交互细节

| 细节 | 实现 |
|---|---|
| Fluent 焦点框 | `:where(button,a,input,select,[tabindex]):focus-visible { outline: 2px solid var(--accent); outline-offset: 1px }` |
| 文本框焦点 | 底部 2px 强调线（Fluent TextBox），`padding-bottom` 同步减 1px 防跳动 |
| 侧栏选中（NavigationView） | 左侧 3px 强调条（`::before` + `scaleY` 过渡）+ 淡强调底 |
| 文件行引导点 | JS 写入的 `·` 用 `visibility:hidden` 隐藏，靠缩进对齐；目录保留 `▸/▾` |
| 减少动效 | `@media (prefers-reduced-motion: reduce)` 关闭全部过渡/动画 |
| 原生控件暗色 | `<meta name="color-scheme" content="dark">` + `:root { color-scheme: dark }` |
| 滚动条 | `scrollbar-width: thin` + 半透明圆角 thumb（`::-webkit-scrollbar` 同步） |
| 布局撑满 | `.layout { align-items: stretch }` + `.content { min-height: calc(100vh - 78px - 24px) }`，`body` 空态 `.hint` 垂直居中 |

### 3.4 网站图标（REQ7-07，2026-10-20 追加）

| 决策 | 内容 | 理由 |
|---|---|---|
| 源图处理 | 1080×1080 JPEG → 居中裁正方 → **多分辨率 ICO**（16/24/32/48/64/128）+ 180×180 PNG | 单尺寸 64px 的插图在标签页里**发糊**（用户反馈）；多档让浏览器按 DPI 自选，16px 那档专门按 LANCZOS 缩过 |
| 交付方式 | **公开只读路由** `/memory/favicon.ico`、`/memory/apple-touch-icon.png` | ① 浏览器在**登录前**就要取标签页图标，登录页没有 Cookie → 不能挂在需认证的 `/memory/static/*` 下；② 不采用 data URI：多尺寸内联会让 HTML 每页膨胀数十 KB |
| 公开边界 | 只公开这两个**固定图片路由**；同一文件在 `/memory/static/icons/` 下**仍 401**（用例断言） | 公开的只是图片本身，不含任何库内容；不因此放宽静态目录的鉴权 |
| 缓存 | `Cache-Control: public, max-age=86400` | 图标是静态展示资源；内容相关响应仍是 `no-store` |
| 可复现 | Pillow 一行 `save(..., format="ICO", sizes=[...])`；脚本与产物见验收 §1.7 | 图标不进构建链，仓库里直接放成品 |

## 8. 风险与回滚

| 风险 | 处置 |
|---|---|
| 暗色导致可读性下降 | 对比度实测入库（`验收.md §1.4`）；三级文字已从 44% 提到 52% |
| `app.js` 依赖的 DOM 被破坏 | 只加类名与 SVG，id 全部保留；功能走查覆盖删除/回收站/恢复 |
| 亚克力在某些环境不生效 | `@supports` 回落纯色，不影响可用性 |
| 视觉不被接受 | 回滚 = `git revert` 该提交并重新构建部署（纯静态资源，无数据风险） |
