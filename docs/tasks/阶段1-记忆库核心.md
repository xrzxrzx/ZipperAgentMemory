## 任务书：阶段 1 记忆库核心（无进程）

- **派发者**：协调者
- **依据**：`docs/design.md` §5（目录结构）、§6.2（安全与并发）、§8 阶段 1；`docs/standards/go-编码规范.md`
- **目标**：实现记忆库的文件读写核心 `pkg/memory`，可被 CLI 调用，为阶段 2/3 打底
- **范围**：
  - `memory/` 目录骨架落地（README.md、index.md、notes/、projects/、structured/、agent/、meta/schema-version）——作为示例初始化
  - `pkg/memory`：
    - `Store` 类型（持有 memory/ 根路径）
    - 路径沙箱校验：`filepath.Clean` + 根内判定 + 符号链接逃逸防护，返回 `ErrPathOutsideRoot`
    - 读：`Read(path) ([]byte, error)`
    - 写：`Write(path, content, overwrite bool) error` —— 临时文件 + fsync + rename 原子写
    - 追加：`Append(path, content) error` —— 自动加时间戳分隔行
    - 元数据辅助：`List(dir)`、`Status()`（文件数/大小/最近变更）
  - CLI 子命令 `zam write/read/append/list/status`（标准库 flag，暂不引 cobra）
  - **不做**：watcher、SQLite 索引、MCP、git（阶段 2+）
- **验收标准**：
  - 单元测试覆盖：路径穿越被拒（`../`、绝对路径、符号链接逃逸）、原子写、overwrite 语义、append 时间戳
  - `zam write/read/append/list/status` 对 memory/ 正确读写
  - `go test ./...` 全绿；`go vet ./...` 零告警
- **交付物**：`pkg/memory/*`（含测试）、`cmd/zam/`、`memory/` 示例骨架
- **约束**：遵守编码规范；新增第三方依赖须先经协调者批准；提交 `feat(memory): 记忆库文件读写核心` 等 Conventional Commits
- **DoD**：验收用例全部通过，测试报告留档（`docs/验收/阶段1.md` 由协调者汇总）
