## 4. 偏离与注意事项

1. **`Commit()` 签名变更**（`error` → `(bool, error)`）：任务书要求 git-commit 输出「成功/跳过无变更」，调用方必须可知提交结果；提交管线逻辑（add -A → diff 判空 → commit）原样保留。全部 11 处既有测试调用点同步适配并补 committed 断言。
2. **`hasNonGitEvent` 移除**：原服务于「watcher 去抖批次内提交」的 `.git` 事件滤除（防反馈环）。批次内提交已整体移除，函数成为死代码，连同其测试一并删除；防反馈环兜底由 Commit 的「无暂存变更跳过」继续承担（单测覆盖）。
3. **RunDaily 失败语义**：Commit 失败仅记日志并顺延次日重试，不终止循环（守护进程语义）；仅 ctx 取消或 hour 越界返回错误。
4. **nextDelay 边界语义**：恰在 hour:00:00 整点视为「今日已过」顺延明日（与 cron "0 hour * * *" 一致），避免进程在整点重启时同槽重复触发；文档与测试均已固化。
5. **可注入时钟**：`AutoCommitter.now` 为未导出字段（同包测试直接赋值），不污染公开 Options API；`commitMessage` 仍用真实 `time.Now()`（提交信息不参与调度断言）。
6. **版本号未变更**：保持 v0.4.0（任务书未要求升版；cmd 与 pkg/mcp.Version 同步约定不变）。
7. **`-allow-ips` 空值语义**：空 = 不限制（本地模式无感知，向后兼容）；非空时未命中一律 403（fail closed，含无法解析远端）；IPv4 与 IPv4-mapped IPv6 归一匹配。
8. **Windows 实测说明**：curl 400 为 PowerShell 转义问题（见 §3），验收证据均以 Invoke-WebRequest 规范请求为准；IPv6 真实进程监听受本机限制，由单测覆盖。
