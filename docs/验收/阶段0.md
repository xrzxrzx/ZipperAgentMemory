## 3. 偏离与注意事项

1. **go 命令不在沙箱 PATH**：任务书称「PATH 已更新」，但 pwsh 会话中 `go` 不可用；定位到实际安装路径 `C:\Users\xrzxr\sdk\go1.26.7\bin\go.exe`，全部命令显式前置 PATH 执行。后续阶段执行命令需同样处理。
2. **make 未安装**：无法直接跑 `make build/test/run`，已用等价 go 命令逐条验证（见 2.6）；Makefile 为 GNU make 语法，Windows 需先装 make（如 `scoop install make`）。
3. **go.mod 版本写法**：`go mod init` 默认生成 `go 1.26.7`，按任务书要求改为 `go 1.26`（Go ≥1.21 允许省略补丁号）。
4. **显式 -o 不自动补 .exe**：Windows 上 `go build -o bin/zipper-agent-memoryd` 按原名生成（无 .exe 后缀），但为合法可执行 PE；不影响后续 Linux 交叉编译（目标平台本就无后缀）。
5. **占位包仅含 doc.go**：`pkg/memory|index|mcp` 当前为空包，`go vet`/`go test` 均通过；符合规范 §1.2（每包必有包级注释）。
