## 6. 偏离与注意事项

1. **索引库默认位置（实现决策）**：任务书未指定 db 路径，实现为 `memory/` 同级 `.zipper-agent-memory.index.sqlite`（`-db` 可覆盖）。理由：a) 不进被监听目录树，避免索引自身写入（含 WAL 文件）触发监听事件形成反馈循环；b) memory/ 是 git 仓库（阶段 4），索引是 derived state 不应入库（.gitignore 已忽略）。设计文档 §7 迁移流程（拷 memory/ → 目标机 rebuild）不受影响。
2. **中文检索（实现决策）**：FTS5 unicode61 无法切分连续汉字，故入库/查询双侧用 `tokenizeForFTS` 做 CJK 单字切分（汉字/假名/谚文每字独立 token），查询整体转双引号短语；snippet 用 `untokenizeSnippet` 还原连续中文。语义：多词查询按短语连续匹配（非 OR），符合记忆检索的「精确短语」预期；`memory_search`（阶段 3）沿用同一切分保证一致。
3. **fsnotify v1.10.1 Rename 语义**：该版本 `Event` 无 OldName 字段，Rename 事件携带的是**被移走的旧路径**，新路径以 Create 事件到达（源码注释确认）。故旧路径→Remove、新路径→Upsert/挂监听。Windows 实测 rename 双事件正确（TestWatcherRenameEmitsRemoveAndCreate）。
4. **验收脚本编码陷阱（重要，非产品缺陷）**：本机为中文 Windows + PowerShell 5.1，`Add-Content` 默认按 ANSI/GBK 写入，验收初期中文标记被写成 GBK 字节 → 索引内容乱码 → 中文搜索不命中。经字节级取证确认（`B1 E0…`=GBK「编码探测」）后，验收脚本改用 `[System.IO.File]::AppendAllText/WriteAllText` + `UTF8Encoding(false)` 显式 UTF-8 写入。产品侧无此问题：Go 二进制按 UTF-8 读写（与阶段 1 一致，memory/ 内容约定 UTF-8）；**Linux 目标环境 locale 默认 UTF-8，无此陷阱**。
5. **serve 运行期间执行 rebuild-index 的并发语义**：rebuild 是独立进程，单事务内 DROP+重建两表；若 serve 同时在跑，serve 后续 Upsert 会因表被重建而失败并记日志（derived state 可恢复：重启 serve 或再次 rebuild，符合 R7）。验收 3 按常规流程在 serve 停止后执行。文档建议：重建索引前先停 serve（阶段 4 手册补充）。
6. **fsnotify 目录删除事件**：删除整棵目录时，fsnotify 为目录及其内每个文件分别发 Remove 事件（Windows 实测，TestWatcherDirRemoveFiresFileEvents）；`handlePathGone` 同时摘除该路径下全部已挂监听，避免同名目录重建时被陈旧条目挡住挂监听。
7. **memory/ 骨架 9 文件**：`meta/schema-version` 无扩展名按 `ShouldIndex` 约定不索引（rebuild 报 8 files 为预期行为）；`.tmp-*`（原子写遗留）与隐藏文件（含 `.git/`）均跳过。
8. **Windows vs Linux 差异点汇总**：
   - 信号：Windows Ctrl+C（SIGINT）+ runtime 模拟 SIGTERM；Linux SIGINT/SIGTERM（systemd 优雅停止场景）。停机前 watcher 先 flush 窗口内剩余事件（TestWatcherFlushesOnCancel 保证）。
   - 内存测量：Windows `Get-Process.WorkingSet64`（实测 11.84MB）；Linux `/usr/bin/time -v` 的 Maximum resident set size（方法见 §4.4）。
   - fsnotify 底层：Windows ReadDirectoryChangesW / Linux inotify，事件语义按 fsnotify 跨平台 API 统一处理（Rename/Create 配对语义两平台一致）。
   - **待 Linux 验证**（同阶段 1 建议）：目标环境复跑 `go test ./...`、`/usr/bin/time -v` 内存实测、SIGTERM 优雅退出、inotify 下目录删除/rename 事件细节。
9. **未新增第三方依赖之外的东西**：`pkg/memory` 仅加 1 行 `Root()` 访问器（Rebuild 遍历 memory/ 树所需，不影响既有 API 语义）。
