```

```

测试规模：**68 个测试**（pkg/memory 17、pkg/index 16、pkg/watch 8、pkg/mcp 12、pkg/git 14、cmd/zipper-agent-memoryd 1，新增 16 个）。

**Watch 偶发失败根因与修复**：初跑 `go test ./...` 时 `TestWatcherCreateModifyDelete` 偶发 5s 超时（3 次中 1 次失败）。根因：Windows 上 `go w.Start(ctx)` 的 `addTree` 监听注册与测试写文件之间存在竞态——文件创建先于根目录监听注册时创建事件丢失。修复：测试侧新增 `waitWatched`（轮询 `w.watched` 直到根目录注册完成）作为同步点，`startWatcher` 与 `TestWatcherFlushesOnCancel` 均先等待注册再制造变更。修复后 `./pkg/watch/` 连跑 5 次全部 PASS（1.04–1.78s）。生产代码无此问题：`serve` 启动时先全量重建索引再启动监听，注册窗口内的变更已被 rebuild 覆盖（derived state，design R7）。
